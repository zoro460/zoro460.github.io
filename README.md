# Soham Kale — Portfolio

Personal portfolio for a QA Automation Engineer. Plain HTML, CSS and JavaScript — no build step.

## Files
- `index.html` — the page
- `css/styles.css` — Dark aurora theme
- `js/main.js` — mobile menu, scroll reveal, active nav link, test counter
- `assets/` — photos, favicon, resume (`Soham_Kale_QA_Resume.pdf`)

## Run locally
```bash
python -m http.server 5500
```
Then open http://localhost:5500

## Live site
https://zoro460.github.io — published with GitHub Pages from the `main` branch. Push to `main` to update it.

## Update content
Edit the text directly in `index.html`. To swap the resume, replace `assets/Soham_Kale_QA_Resume.pdf` with a file of the same name.
